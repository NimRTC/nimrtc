## 1. 背景

v1.4 计划 §N6 要一个**更小**的样例：信令交换 + `EngineConfig` + 四个钩子 + N8 的重协商，**其余全是引擎的**。今天 `examples/remote-desktop/` 的宿主侧是 1475 非注释行（`rd_device.cpp` 488 / `rd_verify.cpp` 556 / `rd_viewer.cpp` 431），光 `rd_signalling.hpp` 就 233 行 —— 那不是我说的那个「小」，因为它把设备采集、渲染、输入回传、验证都算进了宿主的工作。

N6 的判据不是「样例 200 行写不写得出来」，而是：

> **「≤200 行跑完一通话」必须是一个可验证的事实，不是一句口号。**

这句话有两个落点：

1. **样例真的 ≤200 非注释行** —— 每次 CI 重新量，涨过 10% 就失败（一个会漂的限制等于一个漂了的说法）。
2. **样例真的跑完一通话** —— CI 的验收腿起两个进程，过 TLS-only 的 TURN 中继，通音频 + 视频 + 控制消息。

本 ADR 记录第 1 点的决定：**怎么量、量什么、阈值是什么、为什么有漂移余量**。

## 2. 决策

### 2.1 决策一：预算 200 行，10% 漂移余量，上限 220

- **预算 200 行**（硬目标）。
- **10% 漂移余量**：实际 ≤ 220 行时**通过**，但**打警告**并把警告写进 CI 日志。
- 实际 > 220 行 → **失败**（门禁红，非零退出码）。

为什么有 10% 余量而不是死守 200：一次「加个错误处理」不该让 CI 红。余量让小的、合理的改动能过，但**连续的**小改动会在 220 那道线前被叫住 —— 那时**改计划**（计划的余量本身也是决定）。预算声明在 `examples/sdk-sample/sample_line_budget.json`（`budget: 200`、`drift_allowance: 0.10`）。

### 2.2 决策二：每次 CI 重新量，本地也能跑

行数判定要**每次 CI 跑**时重新算，还要能**在本地跑**。放进 CI 脚本里就没人能在提交前查了。所以它是一个独立工具 `tools/check_sample_line_budget.py`，CI 三步里的第一步直接调它；本地 `python tools/check_sample_line_budget.py` 同样能查。

### 2.3 决策三：计数规则（「怎么算非注释行」）

量的对象是 `examples/sdk-sample/` 下的**全部** `.cpp` / `.hpp`（不含 `README.md`、不含 `CMakeLists.txt`）。计数规则：

- 空行**不算**。
- `//` 开头的行**不算**。
- `/* ... */` 块注释的**每一行**都不算（**含**第一行与最后一行）。
- 块注释**之后**同一行还有代码的 → **算**（如 `/* x */ int y = 1;` 算 1 行）。
- 字符串字面量里的 `//` **不**当注释。

最后一条是**诚实性问题**，专门写进规则的：信令地址里就有 `http://`，朴素的 `split('//')` 会把那一行的后半段当成注释丢掉 → 行数被**低估** → 预算就漏了。宁可漏判行，也不能低估。

### 2.4 决策四：豁免列表必须为空

计数规则数的是**样例目录下的全部** `.cpp` / `.hpp`，不是某几个指定文件。豁免列表必须为空（或只剩 `README.md` —— 它本来就不被数）：一个非空列表等于给代码开了后门，让人把行数藏到豁免文件里绕过预算。

### 2.5 决策五：度量工具自带自检，验收侧独立复算

- `tools/check_sample_line_budget_self_test.py`：钉住计数器的行为（`http://` 算 1 行、多行块注释不算、块注释后同行代码算 1 行、超限样本被报出、干净样本干净）。
- `tests/acceptance/v1-sdk-sample/line_budget.js`：同一套计数规则在验收侧独立复算（JS），与 Python 门禁交叉验证 —— 验收测试不单方面信任门禁。

### 2.6 决策六：行数是「应用只贡献信令与产品 UI」的证据，不是装饰

行数涨了，说明应用开始做引擎该做的事了 —— 那时要**改计划**，不是改行数。任何把上限提过 200 的提议都必须先改计划（计划 §5 N6-1）。

## 3. 与其它决策的关系

- **N9（macOS install + 下游证明，ADR-034）**：样例要能在**只有安装树**上编译（独立工程，`find_package(NimRTC REQUIRED CONFIG)` + `NimRTC::engine`）。行数预算与「安装树上能编」是同一份证据的两面：宿主只看见安装树的公开面，行数才能算得清。
- **ADR-015（公开 API 基线）**：本片只写样例、工具与 CI，不新增公开符号，不碰基线。
- **ADP 先行者 ADR-031**：引擎管重连策略、宿主管重新协商 —— 样例只写宿主该写的那部分，正是行数能压下来的前提。

## 4. 现状（本 ADR 落笔时）

`examples/sdk-sample/sdk-sample.cpp` 153 非注释行 + `sdk_signalling.hpp` 38 行 = **191 行**，在预算内。`tools/check_sample_line_budget.py --verbose` 与 `tools/check_sample_line_budget_self_test.py` 跑绿，`line_budget.js` 复算一致。
