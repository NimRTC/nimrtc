# NimRTC v0.10.0 — Release Notes

> Status: **Tech Preview** — no API stability commitment through v1.0.0.
> Tag: `v0.10.0` · Target date: 2026-09-14 · Owner: BDFL

## Summary

v0.10.0 is a **consolidation release** sitting between the P1 exit
(v0.9.2 tag cut on the same day) and the P2 kickoff (v0.11.0). It lands
exactly one structural refactor — PAL Slice 1, the inline-forwarder seam
that lets the engine resolve `audio3a` / `codec` / `video_codec`
plugins through a single `pal::*` entry point — and codifies three v0.9
open decisions as ADRs. It is **not** a feature release: no new protocol
capabilities, no new content types, no new third-party dependencies. The
CHANGELOG line item that says "no unreleased changes yet" is also
literally true after this tag lands.

## Highlights

1. **PAL Slice 1** — engine resolves `audio3a` / `codec` / `video_codec`
   plugins through a single `pal::*` seam. Zero runtime overhead; public
   API unchanged. See `docs/adr/ADR-009-pal-slice-1.md` and
   `docs/zh/architecture.md` §6.
2. **CHANGELOG hygiene** — v0.9.2-era work (~290 lines: vendor tooling,
   release workflow, HW backends, Opus RFC 7587, DTLS Chrome fixes,
   engine PIMPL refactor, ~26 module tests) is now correctly attributed
   under `## [0.9.2] - 2026-09-14`, not `[Unreleased]`.
3. **v0.9 open decisions closed** as ADRs — see "Decision log" below.
4. **README + CHANGELOG version header** now reads
   `v0.10 (Tech Preview — consolidating v0.9)`.

## Decision log

The four ADRs shipped in this milestone.

### ADR-009 — PAL Slice 1 (engine plugin resolver seam)

Inline forwarders in
`src/engine/include/nimrtc/engine/pal/engine_plugin_resolver.hpp`.
~50 LOC code change. Sets up Slice 2 (self-registration table) and
Slice 3 (compile-time ID validation) for v0.10.x patches.

### ADR-010 — JSON as first-class declarative Profile format

JSON is the first-class declarative Profile format. C++ Builder remains
first-class alongside. Existing `profiles/*.json` files are pinned as
**schema v1.0**. Schema versioning follows SemVer — any profile-format
breaking change bumps MINOR.

### ADR-011 — Teleop metrics caliber (single-hop budget only)

Engine backs the single-hop budget only. End-to-end acceptance
references (DB31/T 1505—2024 / T/SSITS 2003—2023) are the integrator's
responsibility. Prevents engine from accumulating cross-hop protocol
metrics that don't belong in a peer library.

### ADR-012 — Chinese docs layout (`docs/zh/` subdirectory)

`docs/zh/` is the canonical Chinese home. New single-file
`docs/zh/architecture.md` replaces `docs/zh/NimRTC-V2-技术文档.md`
(preserved as a 32-line redirect stub for external-link compatibility).
Independent zh site (docs-zh.nimrtc.dev) deferred to v1.0+.

  P2 relay path first.

## Compatibility / upgrade notes

- **Public API**: byte-identical to v0.9.2 for `nimrtc/engine/engine.hpp`.
- **ABI**: Not committed; experimental through v1.0.0. Pin to a specific
  commit.
- **Project-root cleanliness**: contributors upgrading from earlier
  pre-`ad960eb` checkouts should delete any `build_*` directories at
  the project root before re-configuring (now covered by `.gitignore`'s
  `build*/` rule).
- **No new third-party dependencies.** **No new tooling required.**
