## 6. Schedule placeholder

Per §13 baseline (P2 结束后才评估商业接洽 — 是 §16 开源基线
纪律之一), v0.11.0 跨 **3–5 个月** 是合理的范围：

- Month 1: DataChannel + usrsctp 集成 (longest pole)
- Month 2: SFU relay + sfu-relay 压测可复现
- Month 3: PCM tap 落地 + Profile 库官方化 + 调度实现
- Month 4: AI Agent 接入 demo + Discussions + 首批 RFC
- Month 5 (buffer): 反馈消化 + release notes

This schedule is **placeholder**; the actual breakdown will be set in
the v0.11.0 milestone plan, to be authored when v0.10.0 ships.
