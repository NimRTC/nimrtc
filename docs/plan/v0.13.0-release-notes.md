## Highlights

- **API stability framework** — `NIMRTC_API_VERSION_MAJOR=1,
  MINOR=0, PATCH=0, PRE_RELEASE="alpha.1"`,
  `NIMRTC_API_STABLE/UNSTABLE/DEPRECATED(msg)` classification
  markers, `nimrtc::core::api_version::*` namespace constants,
  ADR-015 stability policy. Every public header under
  `src/**/include/nimrtc/**` now carries a stability classification;
  `tests/test_api_classification` 2/2 PASS
  (`headers=89 stable=107 unstable=6 deprecated=8
  missing_markers=0`).

- **P1 UAF-DTLS type-system hardening** —
  `ITransportStack::dtls_weak()` interface in all three
  media-stack implementations; the engine migrates `Impl::dtls`
  + `Impl::datachannel_transport_cookie` from raw `IDtlsSession*`
  to `std::weak_ptr<IDtlsSession>`. 14 use sites use
  `if (auto d = impl_->dtls.lock()) { ... }` that auto-expires on
  `close()`. P1 UAF-on-DTLS class is closed at the type-system
  level. v0.12.0 P0 `is_open()` guards stay as
  defence-in-depth. New regression test
  `v013_dtls_weak_expires_after_close` in
  `tests/test_engine_plugin_loading.cpp`.

- **PAL Slice 1.5** — `pal::MakePluginOpts` named-arguments
  struct, C++20 `auto Resolver` template parameter overload on
  `pal::make_plugin`, 9 `engine.cpp` plugin-load call sites
  migrated to the new shape, 6 new `pal::resolve_*` forwarders
  (`resolve_bwe`, `resolve_scheduler`, `resolve_video_sink`,
  `resolve_video_source`, `resolve_video_receiver`,
  `resolve_video_sender`) so the resolver header is now
  symmetric across the 9 plugin categories the engine uses.
  Per-call-site arg count drops from 9-10 positional to 5
  positional + 1 struct. Public `NimRTCEngine` API byte-
  identical to v0.12.0-post1.
  `tests/test_engine_plugin_loading` 27/27,
  `tests/test_audio3a_tap` 15/15,
  `tests/test_video_source` 13/13 PASS on Windows MSVC.

## Notes

- **Public API surface diff vs `v0.12.0-post1`**: additive only.
  - **New header**: `src/core/include/nimrtc/core/api_version.hpp`
    (the `NIMRTC_API_VERSION` framework).
  - **New helpers**: `nimrtc::core::api_version::*` namespace
    constants (`kMajor/kMinor/kPatch/kString/kPreRelease`).
  - **New macros**: `NIMRTC_API_STABLE/UNSTABLE` (visual
    documentation in default mode) and `NIMRTC_API_DEPRECATED(msg)`
    (emits `[[deprecated(msg)]]` warning).
  - **New interfaces**: `ITransportStack::dtls_weak()` returns
    `std::weak_ptr<IDtlsSession>` (additive; existing `dtls()`
    raw getter preserved with `[[deprecated]]` migration hint).
  - **No existing public symbol is modified or removed.**
  - **No existing public symbol is marked DEPRECATED in v0.13.0**
    (the deprecation policy is established; the first
    `NIMRTC_API_DEPRECATED` annotations are reserved for the
    v1.0.0-alpha.2 → v1.0.0-beta.1 window where the public API
    surface starts the additive-only freeze per
    `docs/plan/v1.0-plan.md` §12.2 v1.0.0-beta.1 Gate #5).
- **ABI**: experimental through v1.0.0. Pin to a specific commit.
  ABI commitment per `docs/adr/ADR-015-api-stability-policy.md`
  §Decision 4 starts at v1.0.0.
- **Profile schema**: v1.1 unchanged (the Profile v1.1 transport
  section landed in v0.12.0 — see `[0.12.0] - 2026-10-13`
  release notes).
- **usrsctp 0.9.5.0** still in tree (v1.2.0 removal, per
  `v1.0-plan.md` §2.2).
- **GMSSL TLCP backend** ships in v0.12.0; unchanged in v0.13.0.
- **5 named use-case transport strategies** ship in v0.12.0;
  unchanged in v0.13.0.
