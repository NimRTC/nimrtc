## 1. Goal

`v1.1.0` is a quality + packaging release. It does not add protocols. It makes `v1.0.x`
verifiable and consumable:

- Anyone can reproduce latency/jitter/throughput numbers from `build/e2e/`.
- Timeline seam (ADR-017 Decisions 3–4) is documented as landed: fitted slope + real skew.
- Release matrix is hard green on all four platforms (W3 + W5 closed).
- Downloaded bundles are consumable: `cmake --install` yields `include/` + `lib/` +
  `lib/cmake/NimRTC/`, and `find_package(NimRTC)` resolves without a source build
  (fixes the `v1.0.2` known issue where bundles shipped only the vendored third-party stack).

Out of scope: SFU-1 / DC-3 / BENCH-1 SFU parts, new codecs, mobile bindings,
production deployment guarantees.
