## 1. Goal

v1.1 是质量 + 打包版本，v1.2 是遗留加固版本。只做三件事：

1. 把传输栈的四个残留 seam 补齐并让 engine 真正消费它们。
2. 把媒体/RTP 与 DTLS 的已知缺口（有时钟率、有 IPv6、有重握手）修到可验证。
3. 把 v1.1 Track A/C/D 还缺的实证（Linux 下游证明、Linux bench 首绿、四平台发布腿全绿、CHANGELOG 1.1.0）补齐。

不做：新编解码、新协议（SFrame/MLS/DTLS 1.3 强制）、SFU 轨道、生产部署保证。

## 4. Sequencing（并行线）

```
线 A（传输栈）: T1 → T2 → T3；T4 文档可并行
线 B（媒体/策略）: M1 + M2 + M3（互不依赖，可并行）
线 C（DTLS）: D1 + D2 + D3 + D4（同文件不同函数，串行提交、并行开发后 rebase）
线 D（打包/基准）: P1 + P2（CI 实证）→ P3 → P4
线 E（OHOS）: O1 本地验证（不挡 A–D）
```

- 每线 ≤ 400 LOC/PR；公共头改动只 additive（`open/close`、`last_recv_packet`、`rehandshake` 均为非纯虚默认实现）。
- `classify-*` 无需重跑（新增方法带 `NIMRTC_API_UNSTABLE` 标记 + `<nimrtc/core/api_version.hpp>` 引入）。
- 每 PR 必跑 `ctest` 相关子集 + `scripts/check-release-freeze.sh`（api freeze 不红）。
