# Slice: v1-game-source

## 目的
M1 单机闭环第一步：合成 2D 打地鼠游戏画面当内存帧源灌入（60fps 起步），复用远控设备端现有采集泵链路，不另起采集后端。依据 Demo 计划 §4.1 与 §8 M1。

## 范围
- examples/remote-desktop/rd_device.cpp
- examples/remote-desktop/game_source.hpp
- tests/acceptance/v1-game-source/acceptance.test.cjs

## 需求
1. 合成游戏画面源（打地鼠，60fps 合成画面起步）
2. 游戏画面当内存帧源灌入现有设备端采集泵
3. 不破坏现有远控采集行为（默认关闭，显式开关开启）

## 验收标准
1. 合成打地鼠画面以帧计数叠加模式按 60fps 灌入，帧序号单调递增；验证方式：单机跑远控单机脚本 30 秒，观察端日志解码计数大于 0 且渲染计数大于 0
2. 设备端新增游戏源开关，缺省走原有真实屏幕采集链路，只有显式传参才走合成游戏源；验证方式：不传参跑现有单机回归通过，传参跑合成源出图
3. 合成源分辨率默认 720p 地板保可读，帧率可配；验证方式：读源配置宽高帧率默认值断言
4. 本片不碰控面传输配置，不碰数据通道控面；验证方式：确认本片改动不含控面传输与数据通道改动

## 风险
- 合成源帧率抖动导致裁判数抖动；应对：先固定 60fps 步进驱动，后续再做 pacing
- 与真实采集共用采集泵产生分支污染；应对：开关隔离，默认路径零改动
