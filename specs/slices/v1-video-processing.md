# Slice: v1-video-processing

## 目的
M1 单机闭环第二步：合成游戏画面经内存帧源进编码器（硬件编码优先，无卡回落到软件编码），为单机闭环提供可解码码流。依据 Demo 计划 §3、§8 M1 与 §9。

## 范围
- src/modules/video_source/src/video_source.cpp
- src/modules/video_source/include/nimrtc/video_source/video_source.hpp
- tests/acceptance/v1-video-processing/acceptance.test.cjs

## 需求
1. 内存帧源支持游戏源所需的 720p 与 60fps 以及帧序号起点可配
2. 编码走现有 H264 路，硬件优先，无卡不静默降级，由调用方显式选后端
3. 单机闭环解码计数大于 0 且渲染计数大于 0

## 验收标准
1. 源配置宽高帧率与序号起点可配且默认值有断言；验证方式：单元断言源配置默认值与赋值生效
2. 合成源输出平面格式经编码后可被解码，单机闭环解码计数大于 0 且渲染计数大于 0；验证方式：跑远控单机脚本 30 秒软件后端全绿
3. 无卡机器不静默降级：硬件后端在无卡机上硬失败，软件后端可跑；验证方式：文档与参数行为一致，构建命令见计划 §9（含硬件编解码与软件编码开关）
4. 本片不改输入绑定与质量评估与引擎时间线接口；验证方式：本片改动仅限视频源模块

## 风险
- 硬件编码无卡环境失败；应对：门禁只跑软件后端，硬件由本地有卡机手动验
- 720p 与 60fps 平面格式内存带宽抖动；应对：先固定步进，后续再做 pacing
