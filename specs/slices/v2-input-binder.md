# Slice: v2-input-binder

## 目的
实现视频帧与输入事件的绑定功能，确保每个输入事件都能准确关联到对应的视频帧时间戳，为后续的输入回放和分析提供基础支持。

## 范围
- src/modules/rd_input/ref_frame_binder.hpp
- src/modules/rd_input/event_codec.cpp

## 需求
无

## 验收标准
1. 实现将输入事件与视频帧时间戳绑定的功能；验证方式：单元测试验证输入事件与对应帧时间戳的绑定关系正确
2. 绑定后的数据结构能正确序列化和反序列化；验证方式：序列化后数据通过解码能还原原始绑定关系
3. 处理边界情况（如时间戳超出范围的事件）；验证方式：测试传入非法时间戳时系统能正确处理并返回错误码

## 风险
无
